# Sistema de Inventario y Ventas SaludPlus

Sistema en desarrollo para gestionar inventario, ventas y control operativo de la farmacia SaludPlus.

## Descripción

Este proyecto busca centralizar las operaciones principales de la farmacia en una sola aplicación, con foco en:

- Control de productos y stock.
- Registro de ventas.
- Seguimiento de movimientos de inventario.
- Apoyo a la toma de decisiones mediante información clara y ordenada.

## Estado del proyecto

El proyecto se encuentra en fase inicial. Todavía no hay código funcional, por lo que este repositorio servirá como base para documentar el alcance, la evolución y las decisiones técnicas.

## Alcance inicial

Las primeras funcionalidades previstas son:

- Edición y consulta de productos.
- Gestión de entradas y salidas de inventario.
- Registro de ventas.
- Control básico de existencias.

## Metodología de trabajo

El desarrollo se está organizando con Scrum como metodología de trabajo del equipo.

## Tecnologías

Las tecnologías definitivas todavía están por definirse.
